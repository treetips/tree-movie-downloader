# アプリケーションの更新

## 更新の条件

- アプリケーションのセマンティックバージョンと、公開先の `update-info.json` が示す最新バージョンを比較し、
  新しいバージョンが見つかるかどうかで判定します。
- 比較するのは `Major.Minor.Patch` の3要素です。プレリリース表記やビルド番号は現時点では扱いません。

## 仕組み

- 配布物は **GitHub Releases** にホストします。
  - `https://github.com/treetips/tree-movie-downloader/releases/latest/download/update-info.json`（更新情報）
  - `https://github.com/treetips/tree-movie-downloader/releases/download/<tag>/Tree-Movie-Downloader-v<version>-macos.zip`（アプリ本体）
- `update-info.json` は `version` / `url` / `sha256` を持ちます。
- アプリは更新情報を取得し、`url` のZIPをダウンロードして SHA-256 を検証します。
- ZIP内の `.app` を検証・展開し、実行中のアプリと置き換えて再起動します。

## 更新確認の起動経路

- macOS メニューバーの `Tree Movie Downloader` → `アップデートを確認`
  - 手動チェック。結果（更新あり / 最新 / 失敗）はダイアログで表示し、
    失敗時を除きタイトルバー右端の更新エリアにも反映します。
- アプリケーション起動時
  - バックグラウンドで自動チェック。ダイアログは表示せず、更新が見つかった場合は
    タイトルバー右端の更新エリアに反映します。
- About画面
  - `アップデートを確認` ボタン（手動チェック）。メニューバーと同じ挙動で、
    結果はダイアログとタイトルバー右端の更新エリアの双方に表示します（確認失敗時は
    更新エリアを変更しません）。
  - 更新がある場合は `インストール` ボタンも表示します。確認ダイアログを経てインストールします。

## インストールの流れ

1. タイトルバー右端の更新エリアにある `アップデートが有ります` をクリックします。
2. インストール確認ダイアログが表示されます。
3. `インストール` をクリックするとダイアログが閉じ、更新エリアが `インストール中` に変わります。
4. ダウンロード中は受信バイト数に基づく進捗率（%）と確定バーを表示します。
5. ダウンロード後は検証・展開・配置の段階を不確定バーで表示します。
6. 完了すると新しいバージョンを起動し、旧プロセスを終了します。
7. 失敗した場合は赤い `インストールに失敗` カードに切り替わり、`再実行` でダウンロードからやり直せます。
8. 開発ビルドなど実行中のアプリが `.app` の中に無い場合は終了せず、展開したアプリをFinderで表示します。

## 更新エリア仕様

### 更新が有る場合

- タイトルバー右端の更新エリアに `アップデートが有ります` と表示します。
- クリックすると、アップデートのインストールダイアログを表示します。
- 背景色はGPUI Kitのテーマトークン（blue）の青い塗りつぶしとし、テキスト・アイコンは背景色トークンで表示します。

### インストール中の場合

- タイトルバー右端の更新エリアに `インストール中` と進捗の補足を表示します。
- ダウンロード中は `ダウンロード 42%` と確定バーを表示します。総バイト数が不明な場合は
  `ダウンロード中` と不確定バーにします。
- 検証・展開・コピー中は `ダウンロードを検証中`・`展開中`・`アプリを配置中` と不確定バーを表示します。
- 更新エリアはクリックできません。
- 失敗時は背景を赤色にした `インストールに失敗` 表示へ切り替えます。
  - 更新エリア内に `再実行` ボタンを表示し、クリックするとダウンロードからやり直します。
  - 失敗の詳細理由はエラーダイアログとAbout画面のメッセージに表示します。
- インストール中は手動の更新確認を無効化します。

### 更新が無い場合

- タイトルバー右端の更新エリアに `アップデートは有りません` と表示します。
- クリックすると、何もせず更新エリアを非表示化します。
- 更新エリアは10秒後に自動的に非表示化します。
- 背景色は控えめな色、テキスト色はタイトルバーのアプリ名と同様の色で表示します。

## 配布・設定

### 更新ホスト（GitHub Releases）

- GitHub Releases のアセットはフラットで、ネスト階層を配信できません。
- Release ワークフロー（`.github/workflows/release.yml`）は、手動インストール用の
  `Tree-Movie-Downloader-v<version>-macos.zip`、`SHA256SUMS.txt`、`update-info.json` を同じReleaseに添付します。
- アプリはGitHub Releasesの最新Releaseから `update-info.json` を取得します。
- 外部ツールの配布（`tools-latest`）はpre-releaseのため、アプリ本体の「最新」を隠しません。

### 初回リリース時の注意

- 初回は比較元となる `update-info.json` が存在しないため、Releaseワークフローが初回用の
  `update-info.json` を生成します。2回目以降は公開済みの最新リリースを基準に更新します。
