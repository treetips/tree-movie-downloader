# 一括ダウンロード

複数のURLをサイトごとのキューへまとめて登録し、サイトごとに1件ずつダウンロードする画面です。異なるサイトは同時に処理できます。
yt-dlpを実際に実行し、サイトごとに1件ずつダウンロードします。起動直後のキューは空です。

## 画面構成

```text
┌──────────────────────────────────────────────────────────────┐
│ タイトルバー（右端にバージョン）                            │
├──────────────────────────────────────────────────────────────┤
│ トップメニュー                                                │
├──────────────────────────────────────────────────────────────┤
│ ツールバー                                                    │
│ URLキュー                                                     │
│  サイト別の表 + 表ごとのログ（折りたたみ）                    │
├──────────────────────────────────────────────────────────────┤
│ ステータスバー                                                │
└──────────────────────────────────────────────────────────────┘
```

## URLの追加

- ツールバーの `URLを追加…` から、1行に1件ずつURLを貼り付けて登録します。`http://` または `https://` で始まる行だけを登録し、それ以外は追加しません。
- 前後の空白を除いたURLが完全一致する場合は、キュー内の既存項目・同一入力内の重複のいずれも追加しません。完了・失敗・スキップ済みの項目も重複判定の対象です。
- 動画URL・チャンネルURL・プレイリストURLを受け付けます。
- 動画URLに `list=` が付いている場合は、その動画だけをダウンロードします。ミックス全体を取得したい場合は `/playlist?list=...` 形式のURLを追加します。
- YouTube APIを使用しないため、タイトル・チャンネル名・再生時間は追加時に取得しません。
  - キューの識別子はURLとし、表示時は `https://` と `www.` を省きます。
  - 取得に失敗した場合は、URLの下にエラー内容を表示します。
  - ダウンロード完了・スキップ後は、yt-dlpが取得したタイトルとサムネイルをURL列へ表示します。メタデータを取得できない場合はURLを表示します。
  - タイトルを表示する場合も、その下にURLを併記します。
  - 一覧内のサムネイルは高さを固定し、縦長・横長に応じて幅だけをアスペクト比どおりに変更します。画像は切り取らずに表示します。
  - サムネイルにホバーすると、元画像の幅・高さをそれぞれ50％にしたプレビューを表示します。256px以下の小さい画像は等倍、巨大画像は最大960pxに収めます。
- URL追加ダイアログで画質・音質・コンテナ・ダウンロード先を選択できます。選択した値は、入力したすべてのURLに適用されます。
- コンテナは、画質が `映像なし` 以外のときは映像用（mp4・mkv・WebM）、`映像なし` のときは音声用（m4a・mp3・opus・flac）の選択肢を表示します。
- URLのホストからサイトを判定し、サイトごとのキューへ振り分けます。
- URLを追加しただけではダウンロードを開始しません。画質・音質・コンテナ・DLフォルダを確認してから、ツールバーの `開始する` で開始します。
- 追加直後の初期値は次の通りです。

| 項目       | 初期値                                                           |
| :--------- | :--------------------------------------------------------------- |
| 画質       | `1080p`（ダイアログで変更可能）                                  |
| 音質       | `最高音質`（ダイアログで変更可能）                               |
| コンテナ   | 映像ありは設定画面の共通設定（初期値は `mkv`）、映像なしは `m4a` |
| DLフォルダ | OS標準のダウンロードフォルダ（ダイアログで変更可能）             |

## キュー

| 列         | 内容                                                                                                                       |
| :--------- | :------------------------------------------------------------------------------------------------------------------------- |
| 状態       | 取得中・完了・待機中・失敗・スキップ・一時停止。失敗時は試行回数も表示                                                     |
| URL        | 登録したURL。スキームと `www.` を省略して表示。完了・スキップ後は動画タイトルとサムネイルを表示し、タイトルの下にURLを併記 |
| 画質       | URLごとの画質。行のメニューから変更。ヘッダーから全行を一括変更可能                                                        |
| 音質       | URLごとの音質。行のメニューから変更。ヘッダーから全行を一括変更可能                                                        |
| コンテナ   | URLごとのコンテナ。映像ありは映像用、映像なしは音声用の選択肢。行のメニューから変更。ヘッダーから全行を一括変更可能        |
| DLフォルダ | URLごとのダウンロード先。行のメニューから変更。ヘッダーから一括変更可能                                                    |
| 進捗       | 進捗バー、進捗率、残り時間                                                                                                 |
| サイズ     | ダウンロード済みサイズ / 全体サイズ                                                                                        |
| 操作       | 再試行・キューから削除・再生。アイコンとテキストのボタンを横一列に表示                                                     |

- 画質は `最高画質（自動）` `1080p` `720p` `480p` `映像なし` から選べます。
- 音質は `最高音質` `192 kbps` `128 kbps` `音声なし` から選べます。
- コンテナは、映像ありでは `mp4` `mkv` `WebM`、映像なしでは `m4a` `mp3` `opus` `flac` から選べます。画質を変えると、コンテナも同じ種類の値へ切り替わります。
- 画質・音質・コンテナ・DLフォルダはURLごとに保持し、ほかの行には影響しません。
- 表は横幅いっぱいに広がり、余った横幅はURL列が吸収します。ウインドウを広げても右側に余白が残りません。
- 各行の左端には状態色のボーダーだけを表示し、行の下線は表示しません。
  - 取得中、完了、失敗、一時停止は状態色、待機中とスキップは控えめな色で表示します。
- キューはサイトごとに表を分け、表の見出しにサイト名・件数・取得中件数を表示します。サイト列は設けません。
  - 表見出しの右端に、そのサイトの `一時停止` / `開始`、`再試行`、`空にする` ボタンを表示します。
  - 同じサイト内では同時に1件だけ取得します。
  - サイトが異なる場合は同時に取得できます。
- ツールバーには `URLを追加…`、`開始する`、`キューを空にする` を並べます。実行中は3つとも無効になります。`URLを追加…` は実行中でなければ有効で、セカンダリボタンとして大きく太字で強調します。`開始する` は待機中・一時停止の項目があり、かつ実行中でないときだけ押せ、有効なときはプライマリボタンとして大きく太字で強調します。`キューを空にする` はキューが空でなく、かつ実行中でないときだけ押せます。
- 各サイトの表の下に、そのサイトのログを折りたたみ表示します。
  - 初期状態は閉じています。見出しのクリックで開閉できます。
  - ダウンロード開始時や失敗時に自動で展開することはありません。
  - 見出しにログ件数を表示します。
  - 見出しのクリアボタンで、そのサイトのログだけを消せます。
  - ログ領域の右クリックメニューから `ログをコピー` `ログをクリア` を選べます。コピーは `時刻 レベル メッセージ` の1行形式です。
- 各サイトの表のヘッダーにある `一括` メニューから、そのサイトの待機中の行の画質・音質・コンテナ・DLフォルダをまとめて変更できます。待機中の行がない場合は押せません。
- コンテナの共通設定は新しいURLの映像用コンテナの初期値として使い、追加後は各行から変更できます。映像なしの初期値は `m4a` です。
- ダウンロード先は設定画面で事前に追加したものから選びます。初期値はOS標準のダウンロードフォルダです。かんたんダウンロードでも同じ保存先を選択できます。
- 自動リトライは画面上部の設定から全URLへ適用します。失敗した項目は設定した回数まで再試行し、そのあとは次の項目へ進みます。

## ダウンロード

- `yt-dlp` をPATHから探し、見つからない場合は `/opt/homebrew/bin/yt-dlp` などを確認します。
- ダウンロード開始前に動画IDを確認します。保存先フォルダ直下に同じIDをファイル名へ含むファイルがある場合は、再ダウンロードせず `スキップ` にします。
  - `.part` などの一時ファイルと、サムネイル・字幕・JSONなどの付随ファイルは判定対象外です。
  - プレイリスト・チャンネルURLのように複数件へ展開されるURLは判定対象外です。
  - ファイル名ルールに `${id}` が含まれていない場合は判定できません。
- 画質・音質・コンテナ・DLフォルダ・ファイル名ルールを実際のダウンロードへ適用します。
- 映像ありは `--merge-output-format` と `--remux-video` で選択した映像用コンテナへ変換します。
- `映像なし` はyt-dlpの音声抽出を使い、選択した音声用コンテナ（`m4a` `mp3` `opus` `flac`）へ変換します。音質を選んでいる場合は、変換後のビットレートにも反映します。
- 進捗・残り時間・サイズをyt-dlpの出力から更新します。
- ダウンロード完了・スキップ後に、yt-dlpの出力から動画タイトル・サムネイル・保存先を取得します。プレイリスト・チャンネルURLは、最初に成功した動画の情報を代表表示にします。
- サムネイルはバックグラウンドで取得し、縮小して表示用の画像へ変換します。取得に失敗してもタイトル表示とダウンロード結果は維持します。
- サムネイルにホバーすると、保持した元画像を幅・高さそれぞれ50％のサイズで表示します。
- 保存先フォルダが存在しない場合は作成します。
- 完了・失敗・自動スキップ時に、設定に従って効果音を再生します。OS通知は完了・失敗時に表示します。
- 自動リトライ設定に従い、失敗時に待機して再試行します。認証エラー・非公開動画などは再試行しません。
- HTTP 429（レート制限）は15秒待って再試行します。
- yt-dlpの出力が3分間途切れた場合はタイムアウトとして失敗にします。ダウンロードや変換に時間がかかっているだけでは失敗しません。
- YouTubeの認証が必要な場合は、設定画面の「ブラウザのCookie」でログイン済みのブラウザを選びます。環境変数 `YT_DLP_COOKIES_FROM_BROWSER` が設定されている場合はそちらを優先します。
- yt-dlpの警告は、その項目のサイトのログへ記録します。
- ダウンロード完了後、そのサイトに待機中の項目があれば続けて開始します。

## 操作

- ツールバーの `開始する` で、待機中・一時停止の項目をまとめて開始します。
- 各サイトの見出しにある `開始` / `一時停止` で、そのサイトの取得を開始・停止します。
- 各サイトの見出しにある `再試行` で、そのサイトの失敗した項目をまとめて待機状態へ戻します。
- 各サイトの見出しにある `空にする` で、確認ダイアログを表示してからそのサイトの項目を削除します。
- ツールバーの `キューを空にする` で、確認ダイアログを表示してから全サイトの項目を削除します。
- 行の `再試行` はダウンロードに失敗した項目だけに表示します。`削除` はすべての項目で利用できます。単一ファイルのパスが判別できる完了・自動スキップ項目には、操作列の右端に `再生` ボタンを表示し、クリックするとmacOSの既定アプリでファイルを開きます。実行中は `再試行` と `削除` を無効にしますが、再生可能なファイルの `再生` は利用できます。
- 開始した行の画質・音質・コンテナ・DLフォルダは変更できません。ダウンロード中は無効化し、完了・失敗・中断・スキップ後は値の表示だけにします。
- 全体の進捗はキュー上部のバーとステータスバーに表示します。
- キューが空のときは、`キューは空です` の下に `URLを追加` ボタンを表示します。
- キュー上部の進捗バーは、実行中・待機中・終了状態を問わず常に右側いっぱいに広げます。全項目が完了・失敗・スキップになると、右端に `終了` と表示します。
- 実行中はステータスバーに取得中のURLを表示します。複数サイトで取得中の場合はサイト数を表示します。

## 画面の切り替え

- 画面上部のメニューから「一括ダウンロード」「[かんたんダウンロード](./easy-download.md)」「設定」「About」を切り替えます。かんたんダウンロードから登録した項目も、このキューに表示されます。
- 一括ダウンロード以外の画面を開いても、ステータスバーにはダウンロードの状態を表示します。

## キーボード操作

- `⌘N`: URLを追加
- `⌘Enter`: 開始・一時停止
- `⌘⇧R`: 失敗を再試行
