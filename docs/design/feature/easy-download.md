# かんたんダウンロード

動画URLを1件貼り付けて、保存先を確認するだけでダウンロードを開始する画面です。キューへの追加と開始を分けず、既存のダウンロード処理を共有します。

## 画面構成

```text
┌──────────────────────────────────────────────────────────────┐
│ タイトルバー                                                  │
├──────────────────────────────────────────────────────────────┤
│ トップメニュー                                                │
├──────────────────────────────────────────────────────────────┤
│  かんたんダウンロード                                        │
│                                                              │
│  URL                                                         │
│  [ https://...                                             ]   │
│                                                              │
│  保存先                                                      │
│  [ Downloads                                             ▾ ]   │
│                                                              │
│  [ 詳細設定 ]                                                │
│                                                              │
│  [                    ダウンロード                     ]     │
│                                                              │
│  ── 実行結果 ──────────────────────────────────────────────  │
│  状態・進捗・サイズ・残り時間                                 │
│  動画タイトル・サムネイル                                     │
│  [ 再生 ] [ 保存先を開く ]                                    │
└──────────────────────────────────────────────────────────────┤
│ ステータスバー                                               │
└──────────────────────────────────────────────────────────────┘
```

- 入力欄、保存先、詳細設定、主操作を縦に1列で並べます。
- 詳細設定を開くと、画質・音質・コンテナを表示します。
- 実行結果は直近の1件だけ表示します。
- 画面全体を縦スクロール可能にし、狭い高さでも主操作に到達できるようにします。

## URL

- 画面を開いたときはURL入力欄にフォーカスします。
- `http://` または `https://` で始まるURLを1件だけ受け付けます。
- 空、不正なURL、複数行の入力を検出し、入力欄の近くに理由を表示します。
- YouTubeのプレイリスト・チャンネルURLは受け付けず、一括ダウンロードへの切り替えボタンを表示します。
- 動画URLに `list=` が付いている場合は、その動画だけを対象にします。
- タイトル・サムネイルは追加時には取得せず、入力したURLを対象として表示します。ダウンロード完了・スキップ後にyt-dlpが取得した情報を表示します。

## 保存先と詳細設定

- 保存先の初期値はOS標準のダウンロードフォルダです。
- 設定画面で登録した保存先を選択できます。ドロップダウン内の検索用テキストボックスで保存先を絞り込めます。
- 画質の初期値は `1080p`、音質の初期値は `最高音質` です。
- コンテナの初期値は設定画面の共通設定を使い、映像なしのときは `m4a` を使います。
- 画質を変更すると、コンテナの選択肢を映像用または音声用へ切り替えます。
- ファイル名ルールとブラウザのCookieは設定画面の値を共有します。

## 開始

- `ダウンロード` を押すと、確認画面を挟まず既存キューへ1件だけ追加して開始します。
- 同じURLが既存キューに残っている場合は追加せず、重複していることを通知します。キュー内の完了・保存済み項目と同じURLの場合は、明示的な再ダウンロードとして項目を作り直します。キューから削除した後も再び追加できます。
- 無効なURLの場合は追加せず、入力欄の近くにエラーを表示します。
- かんたんダウンロードは同時に1件だけ実行します。
- 一括ダウンロードなど、別のダウンロード実行中は開始できません。理由を表示します。
- 同じURLが保存済みの場合は再ダウンロードせず、既存ファイルを開ける状態にします。

## 実行中

- 状態、進捗バー、進捗率、ダウンロード済みサイズ、全体サイズ、残り時間を表示します。
- 進捗がまだ不明な場合は `取得中`、進捗が100%に達するまでは `ダウンロード中`、完了前は `変換中` と表示します。
- 主操作は `キャンセル` に切り替えます。
- キャンセル後は `再試行` から同じ項目を再開できます。
- 実行中はURL・保存先・詳細設定を変更できません。

## 完了

- `完了` または `保存済み` を表示します。
- 動画タイトルとサムネイルを、再生・保存先を開く操作の上に表示します。メタデータを取得できない場合はURLを表示します。
- 一覧内のサムネイルは高さを固定し、縦長・横長に応じて幅だけをアスペクト比どおりに変更します。画像は切り取らずに表示します。
- サムネイルにホバーすると、元画像の幅・高さをそれぞれ50％にしたプレビューを表示します。256px以下の小さい画像は等倍、巨大画像は最大960pxに収めます。URLは実行結果の見出しに表示したまま維持します。
- 出力ファイルのパスが判別できる場合は `再生` と `保存先を開く` を表示します。
- 既存の効果音とOS通知を再生・表示します。
- ダウンロード済みファイルは削除しません。

## 失敗

- エラー内容を短く表示し、詳細を折りたたんで確認できるようにします。
- `再試行` を表示します。
- YouTubeの認証エラーには、設定画面のブラウザCookieへの導線を表示します。
- レート制限、非公開、年齢制限、通信エラーなどは、既存のエラー処理を共有します。

## キーボード操作

- 画面表示直後はURL入力欄にフォーカスします。
- `⌘N`: URL入力欄へフォーカスします。
- `⌘Enter`: 開始・キャンセル・再試行を切り替えます。
- `Tab`: URL、保存先、詳細設定、主操作の順に移動します。
