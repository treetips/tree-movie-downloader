# About画面

> アプリ名・アイコン・バージョン・GitHub・Copyright・yt-dlp・ffmpeg・Deno のバージョン表示・アプリとライブラリの更新確認は実装済みです。

- 表形式で表示します。

### ✏️ バージョン番号

#### 静的ラベル

- 固定で `バージョン` と表示。

#### 動的ラベル

- `1.0.0` の部分はアプリケーションのバージョン番号です。
- `Major` `Minor` `Patch` を使った [セマンティックバージョニング](https://semver.org/lang/ja/) を採用します。

#### バージョニング例

```text
1.0.0 : 初期バージョン
1.0.1 : バグを修正した
1.1.0 : 機能強化を行った
1.1.1 : 機能強化のバグを修正した
2.0.0 : 互換性を保証できない大きな機能強化を行った
```

## ✳️ アップデート

アプリ本体とライブラリの更新状態を、見出し・状態・結果メッセージを横に並べた2列で表示します。インストール・再実行ボタンは、2列に跨る下段の1行にまとめて表示します。

### ✏️ アップデートを確認

表の下（カード内）に、共通の確認ボタンを表示します。

#### ボタン

- `アップデートを確認` ボタンをクリックすると、アプリ本体とライブラリ（yt-dlp、ffmpeg/ffprobe、Deno）の両方を確認します。
- 両方の確認結果を集約して1つのダイアログで通知します。片方の確認に失敗しても、成功した側の更新情報・最新状態は保持します。
- 更新がある場合は、2列の下にまとめた `インストール` ボタンからインストールできます。
- どちらも最新の場合は、アプリとライブラリが最新であることを示すダイアログを表示します。
- `アップデートを確認` ボタンは、どちらかの確認中・インストール中は非活性にし、確認中はローディング表示にします。

### ✏️ アプリ更新

アプリ本体だけの状態・メッセージ・操作を表示します。

#### ステータス

- 現在の状態を短い文で表示します。
  - 未確認: `アプリを確認していません。`
  - 確認中: `アプリの更新を確認しています…`
  - 最新: `アプリは最新です。`
  - 確認失敗: `アプリの更新を確認できませんでした。` と理由
  - 更新あり: `アプリを vX.Y.Z にアップデートできます。`
  - インストール中: `アプリをインストール中: ダウンロード 42%` など
  - 失敗: `アプリのインストールに失敗しました。` と理由

#### ボタン

- アプリ更新がある場合は `インストール` ボタンを表示し、クリックするとアプリ更新の確認ダイアログを開きます。
- アプリ更新に失敗した場合は `再実行` ボタンを表示し、クリックするとアプリ更新をやり直します。
- アプリ更新は成功後に自動再起動せず、`再起動` ボタンを押したタイミングで新しいバージョンへ移行します。

### ✏️ ライブラリ更新

yt-dlp・ffmpeg/ffprobe・Deno の状態・メッセージ・操作を表示します。

#### ステータス

- 現在の状態を短い文で表示します。
  - 未確認: `ライブラリを確認していません。`
  - 確認中: `ライブラリの更新を確認しています…`
  - 最新: `ライブラリは最新です。`
  - 確認失敗: `ライブラリの更新を確認できませんでした。` と理由
  - 更新あり: 更新対象のツール名とバージョン
  - インストール中: `ライブラリをインストール中: yt-dlp をダウンロード 42%` など
  - 失敗: `ライブラリのインストールに失敗しました。` と理由

#### ボタン

- ライブラリ更新がある場合は `インストール` ボタンを表示し、クリックするとライブラリ更新の確認ダイアログを開きます。
- ライブラリ更新に失敗した場合は `再実行` ボタンを表示し、クリックするとライブラリ更新をやり直します。
- ライブラリだけの更新では再起動しません。

### アップデート結果

#### alert

- 更新確認・インストールの状態に応じて、アプリ更新とライブラリ更新の各欄に alert を表示します。初期状態（未確認）では非表示です。色ルールは [共通_alert](./common.md) を参照。
- 確認中・インストール中は info、最新は success、更新ありは warning、失敗は error を使います。
- alert の内容は各更新の最新状態で置き換わります。
- 確認失敗はダイアログで通知し、既存の更新状態を消さず、成功した側の結果を保持します。

#### 更新ステータスピル

- アップデートを確認した結果は、alert に加えてヘッダー下の右上の更新ステータスピルにも表示します。詳細は [アプリとライブラリの更新](./update-application.md) の「更新ステータスピル仕様」を参照。
- 更新ありの本文は、アプリのみ・ライブラリのみ・両方の状態に応じた専用文言を表示します。
- 右端の `インストール` をクリックすると、利用可能な更新をまとめた確認ダイアログを開きます。両方ある場合はライブラリ→アプリの順に更新し、アプリ更新の完了後は `再起動` ボタンから再起動します。

## ✳️ バージョン情報

- 表形式で表示します。

### ✏️ yt-dlp

#### 静的ラベル

- `yt-dlp` という静的ラベルを表示します。

#### 動的ラベル

- 起動時に準備・更新した yt-dlp のバージョンを表示します。
- バージョンはツールのインストール記録（`~/Library/Application Support/tree-movie-downloader/tools/.installed.json`）から取得します。
- 未取得の場合は `未取得` と表示します。
- アプリのバージョンとは独立して管理します。

### ✏️ ffmpeg

#### 静的ラベル

- `ffmpeg` という静的ラベルを表示します。

#### 動的ラベル

- 起動時に準備・更新した ffmpeg のバージョンを表示します。
- バージョンは yt-dlp と同様に `.installed.json` から取得します。ffprobe は ffmpeg の配布物として一緒に管理します。
- 未取得の場合は `未取得` と表示します。
- アプリのバージョンや yt-dlp のバージョンとは独立して管理します。

### ✏️ Deno

#### 静的ラベル

- `Deno` という静的ラベルを表示します。

#### 動的ラベル

- 起動時に準備・更新した Deno のバージョンを表示します。
- バージョンは yt-dlp と同様に `.installed.json` から取得します。
- 未取得の場合は `未取得` と表示します。
- YouTube の JavaScript challenge 解消に使い、アプリのバージョンや他のツールのバージョンとは独立して管理します。
