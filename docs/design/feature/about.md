- 表形式で表示します。

### ✏️ アプリケーション名

### ✏️ バージョン番号

#### 静的ラベル

- 固定で `バージョン` と表示。

#### 動的ラベル

- `1.0.0` の部分はアプリケーションのバージョン番号です。
- `Major` `Minor` `Patch` を使った [セマンティックバージョニング](https://semver.org/lang/ja/) を採用します。

#### バージョニング例

```text
1.0.0 : 初期バージョン
1.0.1 : バグを修正した
1.1.0 : 機能強化を行った
1.1.1 : 機能強化のバグを修正した
2.0.0 : 互換性を保証できない大きな機能強化を行った
```

### ✏️ アップデートを確認

表の下（カード内）に表示します。

#### ステータス

- 現在の状態を短い文で表示します。
  - 未確認: `更新を確認していません。`
  - 確認中: `更新を確認しています…`
  - 最新: `お使いのバージョンは最新です。`
  - 更新あり: `vX.Y.Z にアップデートできます。`
  - インストール中: `インストール中: ダウンロード 42%` など
  - 失敗: `インストールに失敗しました。` と理由

#### ボタン

- `アップデートを確認` ボタンをクリックすると、アプリ内の更新チェック機能で最新リリースを確認します。
  - アップデートが有る場合は、更新ダイアログからダウンロードとインストールを行います。
  - アップデートが無い場合は `お使いのバージョンは最新です` ダイアログを表示する。
- `アップデートを確認` ボタンは、確認中とインストール中は非活性にし、確認中はローディング表示にする。
- 更新がある場合は `インストール` ボタンを、インストールに失敗した場合は `再実行` ボタンを並べる。
  - `インストール` は確認ダイアログを開く。
  - `再実行` はダウンロードからやり直す。

### アップデート結果

#### alert

- 更新確認・インストールの状態に応じて、カード内にalertを表示します。初期状態（未確認）では非表示です。
  色ルールは [共通_alert](./common.md) を参照。
- 確認中・インストール中はinfo、最新はsuccess、更新ありはwarning、失敗はerrorを使います。
- alertの内容は最新の状態で置き換わります。

#### 更新カード

- アップデートを確認した結果は、alertに加えてタイトルバー右端の更新エリアにも表示します（詳細は [アプリケーションの更新](./update-application.md) の「更新エリア仕様」を参照）。
- アップデートが有る場合は `アップデートが有ります` カード、無い場合は `アップデートは有りません` カードを表示します。
- アップデートチェックに失敗した場合は、更新カードを変更せずalertとダイアログだけで失敗を通知します。

## ✳️ バージョン情報

- 表形式で表示します。

### ✏️ yt-dlp

#### 静的ラベル

- `yt-dlp` という静的ラベルを表示します。

#### 動的ラベル

- 起動時にダウンロードした yt-dlp のバージョンを表示します。
- バージョンはツールのインストール記録（`~/.config/tree-movie-downloader/tools/.installed.json`）から取得します。
- 未取得の場合は `未取得` と表示します。
- アプリのバージョンとは独立して管理します。
