# 設定画面

> 設定画面は、左に項目名、右に内容を置く2カラムで構成します。
> 画面翻訳、更新確認は今後実装します。

## 画面レイアウト

- セクションごとに項目をまとめ、枠で囲んで表示します。
- 各行は、左に項目名、右に内容（チェックボックス・ラジオボタン・プルダウン・スライダーなど）を配置します。
- 説明が必要な項目は、行の右端に情報アイコンを置き、ホバーで説明を表示します。

## 実装状況

| 項目                   | 状態                                             |
| :--------------------- | :----------------------------------------------- |
| OSの通知を表示する     | 実装済み                                         |
| サウンド選択           | 実装済み                                         |
| サウンドの再生         | 実装済み                                         |
| サウンドのランダム選択 | 実装済み                                         |
| 外観モード             | 実装済み                                         |
| 言語選択               | 選択と保存のみ（画面翻訳は今後）                 |
| 文字の大きさ           | 実装済み                                         |
| 背景画像               | 実装済み                                         |
| 背景画像のシャッフル   | 実装済み（ユーザー背景画像のみ）                 |
| 背景画像の不透明度     | コンテンツ領域に反映                             |
| 背景色                 | 実装済み                                         |
| ダウンロード共通設定   | 実装済み                                         |
| ブラウザのCookie       | 実装済み（YouTube認証）                          |
| ファイル名ルール       | 実装済み（ダウンロードに適用）                   |
| 保存先の入力           | 実装済み（ダウンロードに適用）                   |

設定は `~/.config/tree-movie-downloader/settings.json` に保存します。

## ✳️ 変換終了時のアクション

### ✏️ OSの通知を表示する

#### OSの通知を表示するチェックボックス

- `OSの通知を表示する` というラベルのチェックボックスを表示します。

#### ℹ️

- ホバーするとpopoverに説明が表示される。
- 「OS内蔵の通知を表示します。通知の表示はOS側の権限設定が別途必要になります。」というテキストが記述されていること。

### ✏️ サウンドを再生する

#### サウンドを再生するチェックボックス

- チェックを付けると、 `成功時のサウンド` プルダウンが 有効になります。
- チェックを外すと、 `成功時のサウンド` プルダウンが 無効になります。

#### 成功時のサウンドプルダウン

サウンド再生の仕組みは [サウンドの再生](../system.md) を参照。

##### プルダウンの選択肢の表示仕様

| 種別                       | パス                                           |
| -------------------------- | ---------------------------------------------- |
| 同梱のサウンド             | `assets/sounds/success`                        |
| ユーザーが配置したサウンド | `.config/tree-movie-downloader/sounds/success` |

- 上記をまとめてプルダウンに表示します。

- プルダウン選択肢の表示は特殊で、以下のように上部に同梱サウンドを、その後にユーザーサウンドを表示します。

  ```text
  同梱サウンド1.mp3
  同梱サウンド2.mp3
  ユーザーサウンド1.mp3
  ユーザーサウンド2.wav
  ユーザーサウンド3.flac
  ```

- 同梱サウンドもユーザーサウンドもファイル名を昇順でソートします。

- 選択肢の項目名は `ファイル名` を表示します。
  - 同梱サウンドの場合だけ、 `（サンプル）xxx.mp3` という形式で、 `（サンプル）` をファイル名のprefixにしてください。
  - ユーザーサウンドの場合は `ファイル名` を表示します。

### 成功時のランダムチェックボックス

- `ランダム` というラベルでチェックボックスを表示。
- 初期値は `チェック無し` 。
- チェックを有効にすると
  - `成功時のサウンドプルダウン` を 無効にする。
  - `▶️ボタン` を 無効にする。
- チェックを無効にすると
  - `成功時のサウンドプルダウン` を 有効にする。
  - `▶️ボタン` を 有効にする。
- 処理終了時の音声を `ランダム` に切り替えます。
- 同梱されている `サンプル` の音声はシャッフル非対象で、ユーザー音声のみが対象となります。

#### 成功時の▶️

- クリックすると `成功時のサウンドプルダウン` で選択したサウンドを再生します。

#### 成功時のサウンド ℹ️

- ホバーするとpopoverに説明が表示される。

- 以下のテキストが記述されていること。

  ```text
  .config/tree-movie-downloader/sounds/success 配下に音声ファイルを配置すると、自分が用意したファイルを選択することができます。
  サンプル音声は「効果音ラボ https://soundeffect-lab.info/」を利用しています。
  ```

## ✳️ 基本設定

### ✏️ 外観モード

#### 静的ラベル

- `外観モード` という静的ラベルを表示します。

#### 外観モードラジオボタン

- macOSのシステム外観（ライト・ダーク）に追従する外観モードを実装してください。
- 選択肢は以下の通りです。
  - `自動`
  - `ライト`
  - `ダーク`
- 初期値は `自動` です。

### ✏️ 言語選択

#### 静的ラベル

- `言語` という静的ラベルを表示します。

#### 言語選択プルダウン

- 言語（BCP 47）を選択します。
- 選択肢は以下の通り
  - 日本語 (ja-JP)
  - 英語 (en-US)
- `~/.config/tree-movie-downloader/settings.json` で選択した言語情報を保存し、次回起動時に復元します。
- `~/.config/tree-movie-downloader/settings.json` に言語設定が無い場合、利用者の環境のロケールからどの言語かを選択します。選択肢に無い言語の場合、英語を選択します。

#### ℹ️

- ホバーするとpopoverに説明が表示される。
- 「表示言語を切り替えます。画面の翻訳は今後追加します。」というテキストが記述されていること。

### ✏️ 文字の大きさ

#### 静的ラベル

- `文字の大きさ` という静的ラベルを表示します。

#### 文字の大きさラジオボタン

- 選択肢は以下の通りです。
  - `小さい`
  - `標準`
  - `大きい`
- 初期値は `標準` です。

### ✏️ 背景画像

#### 静的ラベル

- `背景画像` という静的ラベルを表示します。

##### プルダウンの選択肢の表示仕様

| 種別                       | パス                                         |
| -------------------------- | -------------------------------------------- |
| 同梱の背景画像             | `assets/images/wallpaper/wallpaper[1-3].jpg` |
| ユーザーが配置した背景画像 | `.config/tree-movie-downloader/wallpaper`    |

- 上記をまとめてプルダウンに表示します。

- プルダウン選択肢の表示は特殊で、以下のように上部に同梱背景画像を、その後にユーザー背景画像を表示します。

  ```text
  同梱背景画像1.jpg
  同梱背景画像2.jpg
  ユーザー背景画像1.jpg
  ユーザー背景画像2.png
  ```

- 同梱背景画像もユーザー背景画像もファイル名を昇順でソートします。

- `背景無し` をプルダウン先頭に表示します。

- 初期値は `背景無し` とします。

- 選択肢の項目名は `ファイル名` を表示します。
  - 同梱背景画像の場合だけ、 `（サンプル）xxx.jpg` という形式で、 `（サンプル）` をファイル名のprefixにしてください。
  - ユーザー背景画像の場合は `ファイル名` を表示します。

- 対応している拡張子は以下です。
  - `.jpg`
  - `.jpeg`
  - `.png`
  - `.webp`
  - `.jxl`（アプリ内でデコードして表示）

- `.avif` と `.webm` は対象外です。`.webm` は動画形式のため、静止画の背景には使えません。

- ユーザー背景画像が `存在しない` または `権限不足で参照できない` 場合、 `同梱背景画像1` にフォールバックします。

- 背景画像はアスペクト比を保ったまま、アプリケーションの中に収まるようように設定してください。

#### ℹ️

- ホバーするとpopoverに説明が表示される。

- 以下のテキストが記述されていること。

  ```text
  .config/tree-movie-downloader/wallpaper 配下に背景画像ファイルを配置すると、自分が用意したファイルを選択することができます。JPG・JPEG・PNG・WebP・JXLに対応しています。
  ```

### ✏️ 背景画像のシャッフル

#### 背景画像のシャッフル時間プルダウン

- ラベル無しのプルダウンのみ。
- `背景画像のシャッフル時間プルダウン` で選択した時間毎に壁紙を `ランダム` に切り替えます。アプリ起動中に動作します。
- 同梱されている `サンプル` の壁紙はシャッフル非対象で、ユーザー壁紙のみが対象となります。
- macOSの壁紙のシャッフル機能を模しています。直前の壁紙とは異なる画像を選びます。
- 画像の切り替えは約0.4秒のクロスフェードで行います。

##### 背景画像のシャッフル時間プルダウンの選択肢の表示仕様

- 1分ごと
- 5分ごと
- 15分ごと
- 30分ごと
- 1時間ごと
- 4時間ごと
- 12時間ごと
- 1日ごと

#### ランダムチェックボックス

- `ランダム` というラベルでチェックボックスを表示。
- 初期値は `チェック無し` 。
- チェックを有効にすると
  - `背景画像プルダウン` を 無効にする。
  - `背景画像のシャッフル時間プルダウン` を 有効にする。
- チェックを無効にすると
  - `背景画像プルダウン` を 有効にする。
  - `背景画像のシャッフル時間プルダウン` を 無効にする。

### ✏️ 背景画像の不透明度

#### 静的ラベル

- `背景画像の不透明度` という静的ラベルを表示します。

#### 背景画像の不透明度スライダー

- 最小 = `0.0` 、 最大 = `1.0` です。
- 初期値は `1.0` です。
- この数値は背景画像の不透明度（0.0〜1.0）です。100%で背景画像がそのまま表示され、0%で表示されません。

#### ℹ️

- ホバーするとpopoverに説明が表示される。

- 以下のテキストが記述されていること。

  ```text
  背景画像の不透明度を調節できます。100%で背景画像がそのまま表示されます。
  ```

### ✏️ 背景色

#### 静的ラベル

- `背景色` という静的ラベルを表示します。

#### 背景色カラーピッカー

- カラーピッカーで背景色を設定することができます。
- 外観モードが `ライト` の場合、初期値は `#FFFFFF` です。
- 外観モードが `ダーク` の場合、初期値は `#1E1E1E` です。

#### リセットボタン

- クリックすると、背景色を初期値に戻します。

#### 背景色テキストボックス

- 現在の値をテキストボックスに表示します。
- 編集可能で、ユーザーが自由に色を入力できます。
- ユーザーが入力して、Enterキーをクリックするとそれを背景色として利用します。
  - 無効な色を入力してEnterされた場合、テキストボックスの枠を赤色にし、変更前の入力値を復元します。
  - 有効な色を入力してEnterされた場合、テキストボックスの枠を通常に戻します。

#### ℹ️

- ホバーするとpopoverに説明が表示される。

- 以下のテキストが記述されていること。

  ```text
  背景画像は高さに合わせて表示し、横幅はアスペクト比を保ちます。左右に余白ができる場合は、その余白部分の色が背景色になります。
  ```

## ✳️ ダウンロード

### ✏️ ファイル名ルール

#### テキストボックス

- ダウンロードするファイル名のルールを入力できます。

- `リセット` ボタンで初期値に戻せます。

- 初期値は次の通りです。

  ```text
  ${uploadDate}_${title} [${duration}][${width}x${height} ${vcodec} ${fps} ${acodec} ${abr}][${id}].${ext}
  ```

- 入力内容は変更時に自動保存します。

- テキストボックスの下にプレビューを表示し、入力に合わせてリアルタイムに更新します。
  - プレビューはサンプル値で生成します。

#### 変数一覧

| 変数名       | 意味             |
| :----------- | :--------------- |
| `uploadDate` | アップロード日   |
| `title`      | 動画タイトル     |
| `duration`   | 再生時間         |
| `width`      | 動画の幅         |
| `height`     | 動画の高さ       |
| `vcodec`     | 映像コーデック   |
| `fps`        | フレームレート   |
| `acodec`     | 音声コーデック   |
| `abr`        | 音声ビットレート |
| `id`         | 動画ID           |
| `ext`        | ファイル拡張子   |

#### 補足

- 画面では `${変数名}` 形式で入力します。

- yt-dlpへ渡す際は `%(変数名)s` 形式へ変換して使用します。

- ダウンロード済みファイルの判定に動画IDを使うため、`${id}` をファイル名に含めておくと、同じ動画の再ダウンロードを防げます。

- 出力例:

  ```text
  20260907_${title} [02h43m04s][1280x720 av01.0.08M.08 60FPS opus 136k][ZqSsDmJI-3s].${ext}
  ```

### ✏️ コンテナ

- 映像用コンテナの共通設定は、新しいURLの初期値として使用します。
- 選択肢は `mp4` `mkv` `WebM` です。
- 画質で `映像なし` を選んだ場合は、一括ダウンロード画面のURL追加ダイアログで音声用コンテナ（`m4a` `mp3` `opus` `flac`）を選びます。初期値は `m4a` です。
- 追加後は一括ダウンロード画面の各行から変更できます。

### ✏️ ブラウザのCookie

#### プルダウン

- YouTubeが「ログインして確認」を求めたときに使う、ログイン済みブラウザを選びます。
- 選択肢は `使用しない` `Safari` `Chrome` `Firefox` `Edge` `Brave` `Vivaldi` `Chromium` `Opera` `Whale` です。
- 初期値は `使用しない` です。
- 選択した値は `yt-dlp` の `--cookies-from-browser` へ渡します。
- 環境変数 `YT_DLP_COOKIES_FROM_BROWSER` が設定されている場合は、環境変数を優先します。

#### ℹ️

- ホバーするとpopoverに説明が表示される。

- 以下の内容が記述されていること。

  ```text
  ブラウザに保存されたCookieをyt-dlpへ渡します。macOSの権限により読み取れない場合は、環境変数 YT_DLP_COOKIES_FROM_BROWSER も利用できます。Safariはフルディスクアクセスが必要です。
  ```

## ✳️ 保存先

- ダウンロード先として使うフォルダを、テキストエリアに1行に1件、フルパスで入力します。
- テキストエリアの初期値は空です。
- OS標準のダウンロードフォルダはテキストエリアには表示せず、URL追加ダイアログと `DLフォルダ` のプルダウンの先頭に必ず表示します。
- 入力内容は変更時に自動保存します。
- `パス順に並べ替え` ボタンで、入力したパスを昇順に並べ替えます。
- 登録した保存先は、URL追加ダイアログのダウンロード先プルダウンと、一括ダウンロード画面の `DLフォルダ` 列で選択できます。
- 保存先は `~/.config/tree-movie-downloader/settings.json` に保存します。OS標準のダウンロードフォルダは保存対象外です。
