# トップメニュー

> 画面上部のメニューと画面切り替え、タイトルバー右端の更新エリアは実装済みです。

## メニュー

ウィンドウ上部に、アイコンとラベルを並べたメニューを表示します。選択中の画面は背景色で示します。

- [一括ダウンロード](./batch-download.md)
- かんたんダウンロード
- [設定](./settings.md)
- [About](./about.md)

## 画面

- 一括ダウンロード: キューとログを表示します。
- かんたんダウンロード: 画面の場所のみ用意し、内容は今後実装します。
- 設定: アプリ全体の設定とダウンロードの共通設定を表示します。
- About: アプリ名、アイコン、バージョン、GitHub、Copyrightを表示します。

## タイトルバー

- 左側にアプリアイコンとアプリ名を表示します。
- 右端にバージョンとアップデートエリアを表示します。
- アップデートエリアは、macOSの閉じるボタンがあるタイトルバーの右端に置きます。

## アップデート通知

- 更新チェックの結果を、タイトルバー右端の更新エリアに表示します。
  - 表示のきっかけは、アプリケーション起動時の自動チェックと、`About画面` の `アップデートを確認` ボタン・メニューバーの `アップデートを確認` による手動チェックです。手動チェックで失敗した場合は表示を変更しません。

### 更新確認中の場合

- `アップデートを確認中` とスピナーを表示します。
- エリアはクリックできません。

### アップデートが有る場合

- `アップデートが有ります` と表示します。
- クリックすると、アップデートのインストールダイアログを表示します。
- GPUI Kitのテーマトークン（primary）を背景色・テキスト色に使います。
- ホバーするとカーソルをポインターにし、クリックできることが分かるようにします。

### インストール中の場合

- インストール開始後は `インストール中` を表示します（ダイアログは閉じます）。
- ダウンロード中は `ダウンロード 42%` のような進捗率とプログレスバーを表示します。
- 検証・展開・コピー中は段階に応じた文言と不確定バーを表示します。
- エリアはクリックできません。完了するとアプリは新しいバージョンで再起動して終了します。
- 失敗時は背景を赤色にした `インストールに失敗` エリアに切り替え、中の `再実行` で
  ダウンロードからやり直せます。

### アップデートが無い場合

- `アップデートは有りません` を表示します。
- クリックすると更新エリアを非表示にします。10秒後には自動的にも非表示になります。
- 背景色は透明で目立たない色にします。

## サイドナビを使わない理由

- サイドナビは横幅を260px使うため、キュー表の表示幅を圧迫していました。
- 画面数が4つと少なく、アイコン付きの横並びメニューでも識別できます。
- サイドナビを外したぶんを、キューのURL列と操作列に充てられます。
