# 一覧サムネイルの高さを固定しアスペクト比を維持する

- ステータス: Accepted
- 決定日: 2026-11-27
- 影響範囲: 一括ダウンロード、かんたんダウンロード、サムネイル表示

## 背景

一覧内のサムネイルは16:9の固定幅で表示していた。ショートのような縦長動画では、画像が領域からはみ出したり、必要以上の部分が欠けたりする。

## 決定

- 一覧表示のサムネイルは高さを固定し、幅だけを元画像のアスペクト比から求める。
- 縦長動画では幅を狭くし、横長動画では比率に応じて幅を広げる。画像は切り取らず、全体を収める。
- メタデータ取得前は16:9を既定の比率とし、取得後に実際の比率へ切り替える。

## 理由

高さを固定することで行やカードの高さを安定させつつ、縦長・横長のどちらでも画像をはみ出させずに表示できる。

## 結果

- ショートのサムネイルは狭い幅で表示される。
- 非常に横長の画像では幅が広くなるが、高さとアスペクト比は維持される。
- ホバープレビューの表示サイズは変更しない。
