# ダウンロード初期値のグリッド配置とコンテナ説明

- ステータス: Accepted
- 日付: 2026-11-28
- 影響範囲: 設定

## 背景

ダウンロード初期値のラジオボタンは、左の項目ラベル幅と各選択肢の幅が揃っておらず、縦に見たときに列がばらばらだった。また、コンテナの違いを利用者が判断できる説明がなかった。

## 決定

- 項目ラベルとラジオボタンを2列のグリッドとして整列する。
- 各ラジオボタンの幅を揃え、同じ列の開始位置を一致させる。
- `mp4` `mkv` `WebM` のラベルの右に情報アイコンを表示する。
- 情報アイコンを含む各コンテナのホバーで、その形式の強みをツールチップ表示する。

## 理由

列を固定することで、画質・音質・コンテナの選択肢を上下に比較しやすくする。コンテナの強みを必要なときだけ確認できるため、画面を常に説明文で埋めずに選択を支援できる。

## 結果

- ダウンロード初期値のラベルとラジオボタンが縦に揃う。
- コンテナごとの情報アイコンから強みを確認できる。
- 既存の既定値の保存・適用処理は変更されない。
