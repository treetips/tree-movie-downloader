# 一括ダウンロードのURL追加ボタンを統一

- ステータス: Accepted
- 日付: 2026-11-28
- 影響範囲: 一括ダウンロード

## 背景

一括ダウンロード画面では、ツールバーとキューが空の状態に別々の URL 追加ボタンが表示され、ラベル・サイズ・強調表示が異なっていた。空状態には補足説明文も表示され、操作の目的が重複していた。

## 決定

- キューが空の状態の補足説明文を削除する。
- ツールバーと空状態の URL 追加ボタンを共通の描画処理にまとめ、ラベル・アイコン・サイズ・ツールチップ・無効条件・操作を統一する。
- URL 追加ボタンはセカンダリボタンとして大きく太字にし、文字色を黄色で強調する。

## 理由

同じ操作を同じ見た目と動作で提示することで、利用者が操作先を迷わず、空状態からもツールバーと同じ操作をしやすい。重複した説明をなくし、表示の保守も一か所に集約できる。

## 結果

- 空状態は `キューは空です` と共通の URL 追加ボタンで構成される。
- ツールバーと空状態の URL 追加ボタンは、実行中の無効条件を含めて同じになる。
- URL 追加処理、キーボードショートカット、ダイアログの動作は変更しない。
