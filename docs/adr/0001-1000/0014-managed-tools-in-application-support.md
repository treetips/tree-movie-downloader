# macOSの管理ツールをApplication Supportに配置する

- ステータス: Accepted
- 日付: 2026-11-28
- 影響範囲: 設定・外部ツール

## 背景

yt-dlp・ffmpeg・Deno はアプリが取得・更新する内部管理の対象であり、利用者に編集や差し替えをしてほしくない。これまで設定・サウンド・背景画像と同じ `~/.config/tree-movie-downloader/` 配下に置いていたが、macOSのアプリデータとして標準的な `~/Library/Application Support/` に統一したい。

一方、壁紙やサウンドは利用者が自分でファイルを配置するため、Finder からアクセスしやすい `~/.config/tree-movie-downloader/` に残す。

## 決定

- macOSでは yt-dlp・ffmpeg・ffprobe・Deno とインストール記録を `~/Library/Application Support/tree-movie-downloader/tools/` に配置する。
- 設定ファイル・壁紙・サウンドは `~/.config/tree-movie-downloader/` 配下のままとする。
- 起動時に旧 `~/.config/tree-movie-downloader/tools/` が存在する場合は、新保存先へ移し、旧保存先を削除する。別ボリュームへの移動が必要な場合はコピー後に旧保存先を削除する。
- 新保存先に必要なツールが揃っている場合は新保存先を優先し、旧保存先を削除する。不完全な場合は旧ツールを新保存先へ統合してから旧保存先を削除する。移行に失敗した場合は旧データを削除せず、ツール準備を失敗として利用者に通知する。

## 理由

アプリが独占管理するバイナリと、利用者が編集するファイルを別の領域に分けることで、誤編集を防ぎながらmacOSの保存先の慣例に合わせられる。既存ツールを移行してから旧保存先を削除すれば、更新時の再ダウンロードや設定リセットを避けられる。

## 結果

- 新規インストールの外部ツールは `~/Library/Application Support/tree-movie-downloader/tools/` に配置される。
- 既存インストールは次回起動時にツールを新保存先へ引き継ぎ、旧 `~/.config/tree-movie-downloader/tools/` が削除される。
- 設定・壁紙・サウンドの保存先と既存データは変更されない。
- 新保存先と旧保存先の両方にある場合は、新保存先が完全なら新保存先を、不完全なら旧ツールを統合した新保存先を引き継ぐ。
- 別ボリュームへの移動時はコピー後に旧保存先を削除し、コピーに失敗した場合は旧データを残す。
