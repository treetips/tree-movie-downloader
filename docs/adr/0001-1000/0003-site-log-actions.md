# サイト別ログのコピーとクリア

- ステータス: Accepted
- 日付: 2026-11-23

## 背景

- ダウンロード失敗時の原因調査にはサイト別ログを使うが、全文をコピーしたり、不要になったログを消したりする手段がなかった。
- ログはサイトごとの折りたたみ領域に表示しているため、操作もその単位で完結させたい。

## 決定

- 各サイトのログ見出しにクリアボタンを置く。
- ログ領域の右クリックで「ログをコピー」「ログをクリア」を表示する。
- クリアは対象サイトのログだけを消し、ほかのサイトやキューには影響させない。
- コピーは `時刻 レベル メッセージ` の1行形式で、クリップボードへ渡す。

## 影響

- ログ操作はサイト単位で完結する。
- キューの `空にする` とは独立しており、ログだけを消せる。
