# キューの手動開始とログの初期状態

- ステータス: Accepted
- 日付: 2026-11-23

## 背景

- URLを追加すると対象サイトのダウンロードが自動で始まっていた。
- 画質・音質・コンテナ・DLフォルダは追加後もキューから変更できるが、自動開始のため変更する間もなくダウンロードが進んでいた。
- サイトのログはダウンロード開始時と失敗時に自動で展開され、キューの高さが意図せず変わっていた。

## 決定

- URLを追加しただけではダウンロードを開始しない。
- ツールバーの `URLを追加…` の右に `開始する` ボタンを置き、待機中・一時停止の項目があるときだけ押せるようにする。
- 開始は `開始する` と、各サイトの見出しにある `開始` のどちらからでも行える。
- ログは初期状態では閉じ、ユーザーが見出しをクリックしたときだけ開く。開始時・失敗時の自動展開は行わない。

## 影響

- URLを追加したあとに、画質・音質・コンテナ・DLフォルダを確認してから開始できる。
- 開始を忘れる可能性があるため、追加完了の通知で `開始する` を押すよう案内する。
- ログの開閉はユーザー操作だけで決まり、ダウンロードの進行でキューの高さが変わらない。
