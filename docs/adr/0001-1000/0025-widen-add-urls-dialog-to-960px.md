# URL追加ダイアログの横幅を960pxへ拡大

- ステータス: Accepted
- 日付: 2026-11-28
- 影響範囲: URL追加

## 背景

URL 追加ダイアログの横幅を800pxへ拡大し、ダウンロード先も全幅表示としたが、保存先パスの表示余白をさらに増やしたいため、ダイアログ自体を広くする必要があった。

## 決定

- URL 追加ダイアログの横幅を800pxから960pxへ拡大する。
- 画質・音質・コンテナの1行3列、ダウンロード先の全幅表示は維持する。
- 入力・選択・検索・キューへの追加処理は変更しない。

## 理由

ダイアログを広げることで、URL 入力欄と保存先パスの確認に使える横幅が増える。最小ウィンドウ幅でもダイアログが表示領域内に収まるよう、既存の自動縮小処理は継続する。

## 結果

- URL 追加ダイアログは960pxを希望幅として表示される。
- 小さいウィンドウでは表示領域に合わせて縮小される。
- ダイアログ内のレイアウトと操作は維持される。
