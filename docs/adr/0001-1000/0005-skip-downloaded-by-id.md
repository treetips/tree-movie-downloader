# ダウンロード済みファイルのID判定スキップ

- ステータス: Accepted
- 日付: 2026-11-23

## 背景

- 同じURLを再度キューへ追加すると、画質やコンテナが異なる場合は別ファイルとして再ダウンロードされていた。
- yt-dlpの `--no-overwrites` は同じ出力ファイル名の再取得を防ぐが、拡張子や画質が変わると防げない。
- 保存先フォルダに一度ダウンロードしたファイルがある場合は、ダウンロードを始めずにスキップしたい。

## 決定

- ダウンロード開始前に、yt-dlpのメタデータ取得で動画IDを確認する。プレイリストの展開は最大2件に抑える。
- 1件の動画として解決できた場合、保存先フォルダ直下のファイル名に同じIDが独立した語として含まれるファイルを探す。
- 見つかった場合はダウンロードせず、項目を `スキップ` にして、そのパスをサイトのログへ残す。
- `.part` などの一時ファイルと、サムネイル・字幕・JSONなどの付随ファイルは判定対象外とする。
- プレイリスト・チャンネルURLのように複数件へ展開されるURLは判定対象外とし、通常どおりダウンロードする。
- メタデータ取得に失敗した場合は判定せず、通常どおりダウンロードへ進む。

## 影響

- 画質・コンテナが異なっても、保存先に同じ動画IDのファイルがあれば再ダウンロードしない。
- 判定のため開始前にメタデータ取得が1回増える。プレイリスト・チャンネルでは対象外のため、この分だけ開始が遅れる。
- ファイル名ルールから `${id}` を外すと、保存済みファイルを判定できなくなる。
- 保存先フォルダ直下だけを対象とし、サブフォルダ内のファイルは判定しない。
