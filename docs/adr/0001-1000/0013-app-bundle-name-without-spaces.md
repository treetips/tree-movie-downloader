# アプリバンドル名から半角スペースを除く

- ステータス: Accepted
- 日付: 2026-11-28
- 影響範囲: 更新・配布

## 背景

配布するアプリバンドルが `/Applications/Tree Movie Downloader.app` となり、他のアプリバンドルとは異なり半角スペースを含んでいた。アプリ名を `/Applications/TreeMovieDownloader.app` に統一し、パス指定時の扱いをほかのアプリと揃える必要がある。

## 決定

- アプリ名とアプリバンドル名を `TreeMovieDownloader` とする。
- リリース時に生成する `.app`、`Info.plist` の表示名、メニュー・About画面・通知・リリースタイトルに同じ名前を使う。
- アプリ更新時は配置先のバンドル名を `TreeMovieDownloader.app` に変更する。旧バンドル名でインストールされているアプリも `TreeMovieDownloader.app` へ移行する。
- アプリ更新時は新しいバンドルを先に配置し、旧バンドルをバックアップへ退避した後に起動する。起動に失敗した場合は旧バンドルを復元する。
- 更新前の旧バンドル（同名更新を含む）は即時削除せず、次回以降の起動時に60秒以上経過したバックアップだけ削除する。
- 配置に失敗した場合は旧バンドルを元の場所に残す。
- バンドル識別子、実行ファイル名、設定ディレクトリ、配布ZIP名は変更しない。

## 理由

アプリバンドル名から半角スペースを除くことで、ターミナルや自動化からアプリパスを指定しやすくし、既存のほかのアプリバンドルと命名を揃える。更新時に配置先のバンドル名を変更すれば、新規インストールと既存インストールの更新の両方で同じパスにできる。バンドル識別子と設定ディレクトリを維持すれば、既存の設定やLaunchServicesの登録を引き継げる。旧バンドルを遅延削除すれば、実行中プロセスのサウンド・壁紙などのリソースパスを無効化せずに移行できる。

## 結果

- 新規配布物は `TreeMovieDownloader.app` として生成される。
- 既存インストールもアプリ更新後に `TreeMovieDownloader.app` になる。
- 新アプリの配置に失敗した場合は旧バンドルが元の場所に残り、起動に失敗した場合は旧バンドルを復元する。
- 配置先に同名のバンドルが存在する場合は、更新後のバンドルで置き換える。
- 移行後の旧バンドルは、次回以降の起動時に60秒以上経過したものだけ削除する。
- 同名更新でも起動成功まで旧バンドルのバックアップを保持し、起動失敗時は復元する。
- 既存の設定とアプリ更新の仕組みは維持される。
