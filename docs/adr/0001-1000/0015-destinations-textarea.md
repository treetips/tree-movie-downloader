# 保存先のテキストエリア化

- ステータス: Accepted
- 日付: 2026-11-24

## 背景

- 保存先は1件ずつ行を追加し、参照ボタンや削除ボタンで編集していた。
- 複数のフルパスをまとめて編集したいという要望があった。
- OS標準のダウンロードフォルダは常に選択肢の先頭にあり、編集する必要がなかった。

## 決定

- 保存先の編集を、1行に1件のフルパスを入力するテキストエリアへ変更する。
- OS標準のダウンロードフォルダはテキストエリアに表示せず、選択肢の先頭に常に含める。
- 入力内容は変更時に自動保存し、空行・重複・OS標準のパスは除外する。
- `パス順に並べ替え` ボタンは、テキストエリアの入力行を昇順に並べ替える。
- 行ごとの追加・削除・参照ボタンは削除する。

## 影響

- 複数の保存先をまとめて貼り付け・編集できる。
- OS標準のダウンロードフォルダは保存対象外になり、重複して表示されない。
- フォルダ参照ボタンは使えなくなるため、パスは手入力する必要がある。
