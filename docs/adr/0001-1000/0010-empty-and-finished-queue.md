# キューの空状態と終了状態の表示

- ステータス: Accepted
- 日付: 2026-11-23

## 背景

- キューが空のときはメッセージだけを表示していたため、次に何をすればよいか分かりにくかった。
- キュー全体の処理が終わっても、上部の進捗バーが120pxのままで、終了したことに気づきにくかった。
- 失敗やスキップを含むキューでは、全体の進捗率が100%にならないことがある。

## 決定

- キューが空のときは、`キューは空です` の下に `URLを追加` ボタンを表示する。
- キュー内のすべての項目が完了・失敗・スキップになったときは、キュー上部の進捗バーを右側いっぱいに広げる。
- 終了状態では、進捗率の代わりに `終了` と表示する。
- 空のキューは終了状態とみなさない。進捗バーは従来の幅のままにする。

## 影響

- 空のキューからすぐにURLを追加できる。
- キュー全体の処理が終わったことが、進捗バーの幅と `終了` の表示で分かる。
- 失敗を含む場合でも、進捗率を偽らずに終了したことを示せる。
- 終了状態では進捗バーが行の右側を占めるため、実行中と見た目が変わる。
