# 設定画面で利用可能な横幅を入力欄に使う

- ステータス: Accepted
- 日付: 2026-11-28
- 影響範囲: 設定・レイアウト

## 背景

設定画面のスクロール領域に固定の最大幅を設けていたため、ウィンドウを拡大しても入力欄が広がらず、保存先の複数パスや長いファイル名ルールが折り返しやすかった。

また、基本設定とダウンロードの各領域末尾に、操作に必須でない補足テキストを常時表示していた。

## 決定

- 設定画面のスクロール領域は、利用可能な横幅を上限なく使用する。
- 入力欄は親領域の横幅に合わせて広がり、長いパスや文字列の不要な折り返しを減らす。
- 基本設定とダウンロードの各領域末尾にあった補足テキストは削除する。補足が必要な説明は、既存の情報アイコンに集約する。

## 理由

設定は編集と確認を繰り返す操作であり、入力欄の横幅は作業効率に直接影響する。ウィンドウの拡大に合わせて入力欄も広がれば、不要な折り返しを減らせる。

常時表示の補足は画面の情報量を増やすため、操作に必要な説明だけを残し、追加の詳細は情報アイコンから確認できるようにする。

## 結果

- ウィンドウを拡大すると、設定内の入力欄も利用可能な横幅まで広がる。
- 保存先のテキストエリアは、親領域の全幅を使用する。
- 基本設定とダウンロードの各領域末尾に、対象の補足テキストは表示されない。
- 狭いウィンドウでは、既存の最小ウィンドウサイズと縦スクロールによって編集操作を維持する。
