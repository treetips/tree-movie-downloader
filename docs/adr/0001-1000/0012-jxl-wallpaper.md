# JXL背景画像のデコード

- ステータス: Accepted
- 日付: 2026-11-24

## 背景

- ユーザー背景画像のプルダウンには `.jxl` ファイルが表示されるが、選択しても背景に表示されなかった。
- 壁紙を変更してもアプリ全体へ通知しておらず、再描画されない不具合もあった。
- GPUIの画像デコーダはJPEG XLを扱えないため、拡張子を許可するだけでは表示できない。
- `.avif` も現状のデコーダでは未対応で、`.webm` は動画形式のため静止画の背景には使えない。

## 決定

- 壁紙を変更したときに `WallpaperState` を `notify` し、アプリ全体を再描画する。
- 背景画像の表示処理を共通化し、JXLだけアプリ内でデコードして表示する。
- GPUIの画像バッファはBGRA順のため、デコードしたRGBAをBGRAへ変換して渡す。
- 純Rustの `jxl-oxide` を `image` 連携付きで追加し、デコード結果を `RenderImage` として描画する。
- デコード済み画像はメモリを多く使うため、直近の1枚だけキャッシュする。
- プルダウンで扱う拡張子は `.jpg` `.jpeg` `.png` `.webp` `.jxl` とし、`.avif` は対象外にする。
- `.webm` は動画形式のため対象外とする。

## 影響

- JXLのユーザー背景画像を選択できる。
- JXLは初回表示時にデコードするため、最初の描画だけ待ち時間が発生する。
- JXLのデコードに `jxl-oxide` の依存が増え、ビルド時間とバイナリサイズが増える。
- カラープロファイルの変換は行わないため、広色域のJXLは色味が変わる場合がある。
- AVIFは引き続き表示できないため、プルダウンから除外する。
