# サムネイルのホバープレビューを半分のサイズで表示する

- ステータス: Accepted
- 決定日: 2026-11-27
- 影響範囲: 一括ダウンロード、かんたんダウンロード、サムネイル表示

## 背景

[動画結果のURL併記とサムネイルの原寸プレビュー](./0006-url-and-full-size-preview.md)では、ホバー時に元画像のピクセル寸法で表示していた。元画像が大きい場合、プレビューがウィンドウに対して過度に大きくなることがある。

## 決定

- ホバープレビューは、元画像の幅・高さをそれぞれ50％にして表示する。
- 元画像のバイト列と寸法は引き続き保持し、アスペクト比を変えずに縮小する。

## 理由

半分のサイズにすることで、画像の細部を確認しながらプレビューが占める領域を抑えられる。元画像を保持するため、表示スケールを変更するだけで対応できる。

## 結果

- ホバープレビューの表示サイズは、元画像の幅・高さの半分になる。
- URL併記やサムネイル取得の処理は変更しない。
