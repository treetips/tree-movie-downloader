# 更新通知とツールバーの行を揃える

- ステータス: Accepted
- 日付: 2026-11-28

## 背景

更新通知をヘッダー下へ重ねる際、ページ全体に `pt_3` 相当の上部余白を設けていた。このため、左の URL 追加ボタングループには上部だけ大きな余白が発生し、下側とのバランスが崩れていた。

## 決定

- 更新通知と左のツールバーは、同じ `top_0`・`h_12` の行を共有し、中央揃えにする。
- ページ全体に追加の上部余白を設けない。ボタングループの上下余白はツールバー自身の中央揃えに任せる。
- [ADR 0010](./0010-rex-style-update-status-pill.md) の「本文の上余白を12px相当とする」配置は置き換える。ピルの外観・状態・操作は変更しない。

## 結果

- URL 追加ボタングループの上部だけに出ていた余白を解消する。
- 更新通知の位置を維持したまま、左右のヘッダー要素を同じ行の中央で揃える。
- ページの上下に非対称な追加余白を作らない。
