# 背景画像のクロスフェード

- ステータス: Accepted
- 日付: 2026-11-24

## 背景

- 背景画像の切り替えは瞬時に行われ、ランダム切り替え時に画面が急に変わっていた。
- 前の画像から次の画像へ、滑らかに遷移させたいという要望があった。

## 決定

- 背景画像の切り替え時に、約400msのクロスフェードを行う。
- 前の画像をフェードアウトし、次の画像をフェードインする。両方のレイヤーを重ねて描画する。
- 背景画像の不透明度は、フェード中の両方のレイヤーへ同じように適用する。
- 初回表示ではフェードせず、画像の切り替え時だけフェードする。
- デコード済み画像は `Arc` で保持し、フェード中に再デコードしない。

## 影響

- 画像の切り替えが滑らかになる。
- フェード中は前後の画像を同時に保持するため、一時的にメモリ使用量が増える。
- OSの視差効果を減らす設定が有効な場合、GPUIのアニメーションは即時完了する。
