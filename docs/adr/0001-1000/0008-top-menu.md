# サイドナビからトップメニューへの変更

- ステータス: Accepted
- 日付: 2026-11-23

## 背景

- 左サイドナビが横幅260pxを使い、キュー表のURL列と操作列を圧迫していた。
- 画面数は4つで、サイドナビでなければならないほど多くない。
- アップデートエリアがサイドナビ下部にあり、キューを見ながら状態を確認しづらかった。
- macOSのタイトルバー右端は余白が広く、更新状態を置く場所として使える。

## 決定

- 左サイドナビを削除する。
- 画面上部に、アイコンとラベルを並べたトップメニューを置く。選択中の画面は背景色で示す。
- アプリ名とアイコンはタイトルバーに残す。
- バージョンとアップデートエリアを、macOSの閉じるボタンがあるタイトルバーの右端へ移す。
- サイドナビの横幅を、キューのURL列と操作列の表示に充てる。

## 影響

- キュー表の表示幅が約260px広がり、URLと操作ボタンを見やすくできる。
- トップメニューのぶん、コンテンツの高さが約48px減る。
- ナビゲーションは常に画面上部に見えるため、サイドナビを開閉する操作は不要になる。
- 更新チェックを実装するときは、タイトルバー右端のエリアをクリック可能にしつつ、ウィンドウのドラッグ領域と競合しないようにする必要がある。
- タイトルバーの左側にはmacOSのウィンドウ操作ボタンがあるため、アプリ名と更新エリアが狭い幅で重ならないよう、最小ウィンドウ幅を維持する。
