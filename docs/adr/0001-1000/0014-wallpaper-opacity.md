# 背景画像の不透明度を正しく反映する

- ステータス: Accepted
- 日付: 2026-11-24

## 背景

- 背景画像の不透明度を100%にしても、画像全体に背景色の半透明レイヤーが重なっており、半透明に見えていた。
- 設定画面のプレビューでは不透明度100%の画像がそのまま表示されるため、実際の背景と見た目が一致していなかった。
- スライダーの名称が「透明度」で、100%が透明に見えるという誤解もあった。

## 決定

- 背景画像全体に重ねていた半透明の背景色レイヤーを削除する。
- 背景画像の不透明度は、画像そのものの不透明度としてのみ適用する。100%でそのまま、0%で非表示にする。
- 左右の余白は従来どおり背景色で表示する。
- 設定項目の名称を「背景画像の不透明度」に変更する。

## 影響

- 不透明度100%で背景画像がそのまま表示される。
- 明るい画像では文字が読みにくくなる場合があるため、必要に応じて不透明度を下げる。
- 設定画面のプレビューと実際の背景の見た目が一致する。
