# 更新通知の文字と操作のコントラストを優先する

- ステータス: Accepted
- 日付: 2026-11-28
- 影響範囲: 更新通知
- [ADR 0010](./0010-rex-style-update-status-pill.md) の配色に関する決定を置換

## 背景

更新ありの通知ピルは状態色を35%の透明度で背景に重ね、操作ボタンも同じ状態色を文字色に使っていた。そのため、背景に対する文字のコントラストが低く、特にインストールボタンの文字と背景が見にくかった。

## 決定

- 通知ピルの状態色背景は薄くし、境界線に状態色を使って状態を識別する。
- 本文、インストール進捗の百分率、閉じる操作にはテーマの前景色を使い、状態色の文字と重ねない。
- インストールボタンは Primary、再実行ボタンは Danger の標準ボタンを使用し、テーマが用意する背景色と前景色の組み合わせで表示する。
- 状態アイコンには更新ありを青、失敗を赤、更新なしを緑を使い、色だけに依存させない。

## 理由

標準ボタンの前景色と背景色はテーマ内で対比を保つ設計になっている。通知全体の色を薄くすれば、壁紙やコンテンツの上に重なっても本文を読みやすく、操作部だけを明確なアクセントにできる。

## 結果

- 更新通知の背景は淡くなり、本文と百分率の視認性が向上する。
- インストール・再実行ボタンは標準の状態配色で表示される。
- 更新の状態、操作、閉じる、進捗の仕組みは変更されない。
