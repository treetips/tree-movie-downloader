# 操作列のアイコン＋テキスト表示

- ステータス: Accepted
- 日付: 2026-11-23

## 背景

- キュー表の操作列は、再試行・スキップ・削除をアイコンだけのボタンで表示していた。
- アイコンだけでは意味が伝わりにくく、ボタンのクリック領域も小さかった。
- 3つのボタンすべてにテキストと枠線を付けると横幅が増え、既定のウインドウ幅では表が横スクロールになる。

## 決定

- 操作列のボタンは、アイコンとテキストを併記し、`URLを追加…` などのツールバーと同じ枠線付きのボタンにする。
- 3つのボタンは横一列に並べる。
- 操作列を広げるぶん、表全体のセルの左右余白を16pxから8pxへ詰める。あわせて操作列以外の各列の幅を8pxずつ縮め、セル内の表示幅は変えない。
- ツールチップとアクセシビリティラベルは従来どおり残す。

## 影響

- アイコンだけで意味を推測する必要がなくなり、クリック領域も横に広がる。
- 既定のウインドウ幅では、操作列を含めて横スクロールなしで表示できる。
- 列間の余白がこれまでより詰まり、表全体が少し密度の高い見た目になる。
- URL列の表示幅は変わらない。行の高さも変わらない。
