# ダウンロード初期値をラジオボタンで選択

- ステータス: Accepted
- 日付: 2026-11-28
- 影響範囲: 設定・URL追加・かんたんダウンロード

## 背景

設定画面の `ダウンロード初期値` は、画質・音質を文字列で列挙するだけだった。利用者がラジオボタンから既定値を選択し、その値を新しいURLの初期値として反映できる必要があった。

## 決定

- 画質・音質・コンテナの初期値をラジオボタンで選択できるようにする。
- 画質の初期値候補は `1080p` `720p` `480p` `映像なし`、音質は `最高音質` `192kbps` `128kbps` `音声なし`、映像用コンテナは `mp4` `mkv` `WebM` とする。
- 選択した画質・音質・コンテナを設定ファイルへ保存し、URL 追加ダイアログとかんたんダウンロードの初期値に使用する。
- 既存のURLごとの画質・音質・コンテナは変更しない。

## 理由

ラジオボタンにすることで、選択肢と現在の既定値を一目で確認でき、設定の保存と初期値への反映まで一貫して行える。

## 結果

- 設定画面で画質・音質・コンテナの既定値を選択できる。
- 選択値はアプリ再起動後も保持される。
- 新しいURLを追加する際、ダイアログの初期値に選択値が反映される。
- URL 追加ダイアログ自体の選択肢は変更されない。
