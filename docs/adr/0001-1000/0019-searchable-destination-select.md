# 保存先選択を検索可能なセレクトで表示する

- ステータス: Accepted
- 日付: 2026-11-28
- 影響範囲: URL追加・かんたんダウンロード

## 背景

保存先は設定画面で複数登録できるため、候補が増えると一覧から目的のフォルダを探しにくかった。パスは長く、フォルダ名の一部だけを覚えている場合もある。

GPUI Kit の `Select` は、ドロップダウン内に検索用テキストボックスを表示する検索機能を標準で提供している。

## 決定

- URL追加ダイアログとかんたんダウンロードの保存先選択に、検索可能な `Select` を使用する。
- 検索は保存先パスの大文字・小文字を区別しない部分一致とし、一致した文字を強調表示する。
- 検索用の虫眼鏡アイコンと `保存先を検索` のプレースホルダーを表示する。
- 単一選択、初期値、選択した保存先のダウンロードへの適用、実行中の無効化は変更しない。
- キュー表の行ごとの保存先メニューは、今回の検索対象に含めない。

## 理由

保存先は単一値の選択であり、複数選択や独自トリガーは不要である。標準の検索可能な `Select` を使えば、キーボード操作、アクセシビリティ、選択状態の管理を維持したまま候補を絞り込める。

## 結果

- URL追加ダイアログとかんたんダウンロードで、保存先を文字列で検索できる。
- 検索結果はパスの部分一致で絞り込まれ、一致部分が強調される。
- 既存の保存先の保存・同期・ダウンロードへの適用は変更されない。
