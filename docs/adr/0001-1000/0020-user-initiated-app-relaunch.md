# アプリ更新後の再起動をユーザー操作に委ねる

- ステータス: Accepted
- 日付: 2026-11-28
- 影響範囲: アプリ更新・更新通知・About
- [ADR 0003](./0003-independent-app-and-library-updates.md) のアプリ更新後の自動再起動に関する決定を置換

## 背景

アプリ更新の配置が完了すると、従来は新しいアプリを自動起動し、現在のプロセスを終了していた。Rex は更新完了後も自動再起動せず、利用者が任意のタイミングで再起動できるようになっている。

作業中に突然再起動すると画面の状態が失われるため、再起動のタイミングを利用者に委ねたい。

## 決定

- アプリ更新はダウンロード・検証・展開・配置までを行い、配置完了時点では自動起動・自動終了しない。
- 配置完了状態を保持し、更新ステータスピルと About 画面に緑の完了表示と `再起動` ボタンを表示する。
- `再起動` ボタンを押した場合だけ、配置済みの新しいアプリを起動して現在のプロセスを終了する。
- 再起動に失敗した場合は配置前のアプリへロールバックし、更新失敗状態にして `再実行` から再更新できるようにする。ロールバックに失敗した場合もエラーダイアログを表示する。
- 完了通知を閉じても状態は保持し、About 画面から再起動できるようにする。
- ライブラリだけの更新は従来どおり再起動不要とする。

## 理由

配置と再起動を分離すれば、利用者は作業の区切りで再起動できる。更新完了状態を保持すれば、通知を閉じたり手動で更新確認を実行したりしても、再起動の導線を失わない。

## 結果

- アプリ更新後は旧プロセスのまま作業を継続できる。
- 更新ステータスピルまたは About 画面の `再起動` ボタンから、任意のタイミングで新しいバージョンへ移行できる。
- 再起動失敗時は旧アプリへ戻し、`再実行` から再更新できる。
- アプリとライブラリの更新順序、配布形式、設定保存先は変更されない。
