# 動画結果のURL併記とサムネイルの原寸プレビュー

- ステータス: Accepted
- 決定日: 2026-11-27
- 影響範囲: 一括ダウンロード、かんたんダウンロード、キュー、サムネイル表示

## 背景

[ダウンロード結果に動画タイトルとサムネイルを表示する](./0005-download-result-preview.md)では、一括ダウンロードのURL列をタイトル・サムネイル表示へ切り替えた。しかし、タイトル追加後にURLが見えなくなり、登録内容の確認がしにくい。

また、一覧内のサムネイルは縮小表示であるため、元の画像を確認したい場合に操作がない。

## 決定

- 一括ダウンロードでは、タイトルの下にURLを併記する。かんたんダウンロードは既存のURL見出しを維持する。
- サムネイルにホバーすると、元画像のピクセル寸法でプレビューを表示する。
- キューには、一覧表示用の縮小画像に加えて、元画像のバイト列と寸法を保持する。GPUIでの元画像の描画・デコードはホバーカードを開いたときに行う。
- 原寸プレビューは [`HoverCard`](https://gpui-kit.com/component/hover-card) で表示し、すばやいホバーで点滅しない遅延を設定する。
- 元画像の取得・変換に失敗した場合は、従来どおりタイトルだけを表示し、ダウンロード結果には影響させない。

## 理由

URLをタイトルの下へ併記することで、動画名と登録URLを同時に確認できる。縮小画像と元画像を分けて保持すると、一覧のデコードメモリを抑えながら、必要なときだけ原寸画像を表示できる。

## 結果

- タイトル表示後もURLを確認できる。
- サムネイルのホバーで、元の解像度の画像を確認できる。
- 項目ごとに元画像のバイト列も保持するため、キューが大きい場合はメモリ使用量が増える。
- 非常に大きい元画像はウィンドウ外へ広がる可能性があるが、取得時のバイト数・寸法・デコード割り当てには上限を設ける。
