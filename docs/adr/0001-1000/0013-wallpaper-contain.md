# 背景画像を高さ基準で表示する

- ステータス: Accepted
- 日付: 2026-11-24

## 背景

- 背景画像を `Cover` で表示していたため、画面いっぱいに広がるよう画像の上下または左右が切り取られていた。
- ユーザーの背景画像は正方形が多く、高さを基準にして全体を見せたいという要望があった。
- 余白ができる場合でも、背景色を設定することで目立ちにくくできる。

## 決定

- コンテンツ領域の背景画像は `Contain` で表示し、高さに合わせてアスペクト比を保つ。
- GPUIの`img`は画像のアスペクト比をレイアウトへ反映するため、親の高さを超えることがある。背景画像は専用の要素で親の領域いっぱいに描画し、描画時に`ObjectFit::Contain`で収める。
- 背景画像のレイヤーはコンテンツ領域に置き、タイトルバー・トップメニュー・ステータスバーには表示しない。
- 左右に余白ができる場合は、アプリの背景色をそのまま表示する。
- 設定画面のプレビューも同じ表示方法にする。

## 影響

- 画像の全体が表示され、上下左右の切り取りがなくなる。
- 正方形の画像では高さが画面いっぱいになり、左右に背景色の余白ができる。
- 横長の画像では、ウインドウの横幅に合わせて上下に余白ができる場合がある。
