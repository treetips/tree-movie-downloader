# URL追加ダイアログのダウンロード先を全幅表示

- ステータス: Accepted
- 日付: 2026-11-28
- 影響範囲: URL追加

## 背景

URL 追加ダイアログの横幅を800pxへ拡大しても、ダウンロード先がコンテナと同じ2列の行を共有していたため、長い保存先パスが見切れていた。

## 決定

- 画質・音質・コンテナを1行3列で表示する。
- ダウンロード先を次の行に移動し、ダイアログの横幅一杯で表示する。
- 選択肢、検索、初期値、キューへの適用処理は変更しない。

## 理由

ダウンロード先は保存先パスという長い文字列を確認する必要があるため、他の選択肢と列を共有せず、利用可能な横幅をすべて使う方が適切である。一方、画質・音質・コンテナは短い選択肢を横並びにまとめられる。

## 結果

- ダウンロード先のプルダウンにダイアログ内の全幅が確保される。
- 画質・音質・コンテナは等幅の3列に揃う。
- 保存先の検索・選択・適用動作は維持される。
