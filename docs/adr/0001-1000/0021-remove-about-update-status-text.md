# About画面の更新欄の重複する状態テキストを削除

- ステータス: Accepted
- 日付: 2026-11-28
- 影響範囲: About・アップデート

## 背景

About 画面のアプリ更新・ライブラリ更新の各見出しの下に、状態を表す短文が表示され、見出しや結果メッセージと内容が重複していた。

## 決定

- アプリ更新・ライブラリ更新の各見出しの直下に表示していた状態テキストを削除する。
- 更新状態は、既存の結果メッセージと操作ボタンで伝える。
- 更新処理、通知、ダイアログ、操作の表示条件は変更しない。

## 理由

重複した状態表現をなくし、更新状況の変化を結果メッセージに集中させることで、各欄を簡潔に保てる。更新機能の動作を変えずに表示だけを整理できる。

## 結果

- 各更新欄は見出しと、状態に応じた結果メッセージ・操作で構成される。
- 未確認時に見出しの下へ独立した状態行は表示されない。
- [ADR 0017](./0017-about-update-two-column-layout.md) の2列構成と更新操作の配置は維持する。
