# 開始済み項目のダウンロード設定ロック

- ステータス: Accepted
- 日付: 2026-11-23

## 背景

- キュー表の画質・音質・コンテナ・DLフォルダは、ダウンロード開始後も変更できていた。
- すでに取得を始めた項目や取得が終わった項目の設定を変えても、実際のダウンロードには反映されず意味がない。
- 一括変更メニューから、開始済みの項目まで書き換えられる状態だった。

## 決定

- 待機中の行だけ、画質・音質・コンテナ・DLフォルダを変更できる。
- ダウンロード中の行は、設定のプルダウンを無効化する。
- 完了・失敗・中断・スキップした行は、設定を値の表示だけにする。
- 再試行で待機中に戻した行は、再び変更できるようにする。
- 再試行・スキップ・削除の操作ボタンは、設定ではないため開始後も操作できる。
- 一括変更メニューは待機中の行だけに適用し、待機中の行がないサイトでは押せなくする。

## 影響

- 開始後に設定を変えてしまう誤操作を防げる。
- ダウンロード中の行は設定が無効に見え、終了後の行はボタンではなく値として表示される。
- 再試行する場合は待機中に戻るため、設定を変更してから再開できる。
- 開始済みの行を一括変更しても、その行の設定は変わらない。
