# ダウンロード設定の簡略化

- ステータス: Accepted
- 日付: 2026-11-23

## 背景

- 設定画面に「エラー時: 次の項目へ進む」スイッチがあったが、初期値の「進む」が通常の動作で、変更する意味がほとんどなかった。
- 「同時ダウンロード: 1件」は操作できない静的な表示で、設定する項目ではなかった。
- 同時実行数はサイトごとに1件という仕様で固定しており、画面に表示する必要がない。

## 決定

- 「エラー時」スイッチと、それに伴う設定値・保存項目を削除する。
- ダウンロードに失敗した場合は、設定した回数まで再試行したあと、常に次の項目へ進む。
- 「同時ダウンロード」の表示を削除する。サイトごとに1件という動作は変更しない。

## 影響

- 失敗時に次の項目へ進むかどうかを設定できなくなる。従来の初期値と同じ動作を常に取る。
- 古い設定ファイルに残っている `continue_on_error` は読み込み時に無視される。
- 設定画面から、操作できない情報表示がなくなる。
