# ダウンロード初期値を1080p・最高音質・mp4に統一

- ステータス: Accepted
- 日付: 2026-11-28
- 影響範囲: 設定・URL追加・かんたんダウンロード

## 背景

アプリのダウンロード初期値は、画質 `1080p`、音質 `最高音質`、映像用コンテナ `mkv` だった。汎用性を優先し、多くの機器・アプリで再生しやすい `mp4` を既定値にする必要があった。

## 決定

- 画質の初期値を `1080p` とする。
- 音質の初期値を `最高音質` とする。
- 映像用コンテナの初期値を `mp4` とする。
- 映像なしの音声用コンテナ初期値は `m4a` のまま維持する。
- 設定ファイルに保存済みの利用者の選択値は上書きしない。

## 理由

`1080p` と `最高音質` は既存の既定値であり、`mp4` は再生機器・アプリとの互換性が高い。新規利用者と未設定の項目に共通の初期体験を提供しながら、既存のカスタマイズは保持できる。

## 結果

- 新規インストール・未設定項目は `1080p` `最高音質` `mp4` で動作する。
- 設定画面で選択した既定値は引き続き保存・適用される。
- 既存のキュー項目や保存済み設定は変更されない。
