# 設定画面にダウンロード初期値の選択肢を一覧表示

- ステータス: Accepted
- 日付: 2026-11-28
- 影響範囲: 設定・URL追加

## 背景

設定画面にはコンテナの初期値設定だけが表示され、URL 追加ダイアログで設定できる画質・音質・コンテナの選択肢を一覧で確認できなかった。

## 決定

- 設定画面の左ラベルを `ダウンロード初期値` に変更する。
- 右側に画質・音質・コンテナの選択肢を列挙する。
- コンテナの共通設定は選択可能なまま維持する。
- `URLを追加する際の初期値を上記に設定します。` と表示する。

## 理由

URL 追加時の選択肢を設定画面で確認できるようにし、既定値の考え方を明示する。既存のコンテナ共通設定を残すことで、既定値の変更機能も維持できる。

## 結果

- 設定画面に画質・音質・コンテナの選択肢が一覧表示される。
- コンテナの共通設定は引き続き変更できる。
- URL 追加ダイアログの初期値と選択肢は変更されない。
