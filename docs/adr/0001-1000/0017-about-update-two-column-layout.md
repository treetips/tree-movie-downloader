# About画面の更新状態を2列表示し更新操作を下にまとめる

- ステータス: Accepted
- 日付: 2026-11-28
- 影響範囲: About・アップデート

## 背景

About 画面では、アプリ更新とライブラリ更新の状態が縦に並び、画面の高さを多く使っていた。両者は同じ更新確認の結果を構成する隣接する情報であり、横に並べて比較できる方が効率的である。

また、更新操作が各状態欄の内側にあるため、状態表示の折り返しによってボタンの位置がばらついていた。

## 決定

- アプリ更新とライブラリ更新の見出し、状態、結果メッセージを1行の2列で表示する。
- インストール・再実行ボタンは2列の下にまとめ、2列に跨る1行に表示する。
- アプリ更新とライブラリ更新の操作、状態、ダイアログの仕組みは変更しない。

## 理由

状態を横に並べると両方の更新状況を比較しやすく、操作を独立した下段にまとめることで、メッセージの長さに関係なくボタンの位置を揃えられる。既存の更新処理を変えずに表示だけを整理できる。

## 結果

- アプリ更新とライブラリ更新の状態が横並びになる。
- 更新操作は両欄の下の全幅行に表示される。
- 更新の確認、インストール、再実行の条件は維持される。再起動は [ADR 0020](./0020-user-initiated-app-relaunch.md) のユーザー操作に委ねる。
