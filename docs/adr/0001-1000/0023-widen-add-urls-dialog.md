# URL追加ダイアログの入力案内と横幅を調整

- ステータス: Accepted
- 日付: 2026-11-28
- 影響範囲: URL追加

## 背景

URL 入力欄のラベルは入力形式の説明にとどまり、複数行入力によってまとめてキューへ登録できる利点が伝わりにくかった。また、ダイアログの横幅が560pxだったため、保存先パスが長い場合にダウンロード先の選択肢が見切れていた。

## 決定

- URL 入力欄のラベルを `URLを複数行入力すると一気にダウンロードキューに登録できます` に変更する。
- URL 追加ダイアログの横幅を560pxから800pxへ拡大する。
- 入力・選択・キューへの追加処理、検索、無効条件は変更しない。

## 理由

ラベルで複数行入力の結果を明示し、横幅を広げることで、入力方法と保存先パスを確認しやすくする。ダイアログは表示領域に応じて自動的に縮小されるため、小さいウィンドウでも画面外へのはみ出しは防げる。

## 結果

- URL 入力欄に複数行一括登録の案内が表示される。
- ダウンロード先のプルダウンに以前より多くの横幅が確保される。
- URL の検証、重複判定、保存先の選択・検索、キューへの登録動作は維持される。
