# アプリ表示名とアプリバンドル名を分ける

- ステータス: Accepted
- 日付: 2026-11-28
- 影響範囲: タイトルバー・About・更新・配布
- [ADR 0013](./0013-app-bundle-name-without-spaces.md) の表示名に関する決定を置換

## 背景

ツールバーと About 画面のアプリ名を、読みやすい半角スペース入りの `Tree Movie Downloader` に変更する必要がある。

一方、アプリバンドル名は更新処理、配置先の解決、バックアップ削除、リリースワークフローで共有している。表示名の変更によってバンドル名まで変更すると、既存の更新・移行処理に影響する。

## 決定

- ツールバーと About 画面の表示名を `Tree Movie Downloader` とする。
- アプリバンドル名、実行ファイル名、バンドル識別子、設定ディレクトリ、配布ZIP名は `TreeMovieDownloader` の既存方針を維持する。
- 表示名とバンドル名を別の定数として持ち、表示名をバンドル操作に使用しない。

## 理由

表示名は利用者の可読性を優先し、バンドル名は自動化と更新処理の安定性を優先する。両者を分離すれば、画面の名前だけを変更しても既存インストールの更新や設定の引き継ぎに影響しない。

## 結果

- ツールバーと About 画面には `Tree Movie Downloader` と表示される。
- 配布バンドルは引き続き `TreeMovieDownloader.app` となる。
- 既存のアプリ更新、バックアップ、設定保存の仕組みは変更されない。
