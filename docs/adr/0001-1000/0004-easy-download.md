# かんたんダウンロードを既存キューへ自動登録する

- ステータス: Accepted
- 決定日: 2026-11-27
- 影響範囲: かんたんダウンロード、ダウンロード制御、キュー

## 背景

かんたんダウンロード画面は、動画URLを1件貼り付けてすぐ保存するための入口として用意されている。一括ダウンロードでは、URL追加後に開始操作が必要になり、複数件のキュー管理も表示される。この違いは、ダウンロード処理そのものではなく、登録から開始までの操作を短縮する点にある。

既存のダウンロード処理には、画質・音質・コンテナの適用、保存先の作成、動画IDによる重複判定、自動リトライ、タイムアウト、Cookie、効果音、OS通知がある。これらを複製すると、画面ごとに動作と設定がずれる。

## 決定

かんたんダウンロードは、専用のダウンロード処理を持たず、次の方針で実装する。

- 入力できるのは動画URL1件とし、プレイリスト・チャンネルURLは一括ダウンロードへ誘導する。
- URL・保存先・画質・音質・コンテナを確認すると、既存キューへ1件だけ自動登録し、その項目を直接開始する。
- かんたんダウンロードは同時に1件だけ実行する。別のダウンロード実行中は、終了まで新しい開始を受け付けない。
- 進行・完了・失敗・キャンセル・再試行は、既存キューの項目を参照して表示する。
- 保存済みファイルの検出、通知、効果音、リトライ、Cookie、ファイル名ルールは既存処理を共有する。
- クイック画面から登録した項目も一括ダウンロードのキューに表示し、ファイル自体の削除は行わない。
- タイトル・サムネイル取得、ブラウザ連携、複数URL、ドラッグ＆ドロップは初回実装に含めない。

## 結果

- 入力から開始までの操作が短くなり、初心者が設定を変更しなくても保存できる。
- 既存の信頼性と設定を再利用できるため、動作の重複やずれを防げる。
- クイック画面と一括画面の境遇が明確になる一方、クイック画面の項目は一括画面にも残る。
- 別のダウンロード実行中はすぐには開始できないが、同時実行による競合を避けられる。
