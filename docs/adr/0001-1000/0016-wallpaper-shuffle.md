# 背景画像のランダム切り替え

- ステータス: Accepted
- 日付: 2026-11-24

## 背景

- 背景画像のシャッフル設定は保存されるだけで、実際には切り替わっていなかった。
- 1分を選んでも背景画像が変わらないという報告があった。
- 同梱のサンプル画像はシャッフル対象外としていた。

## 決定

- 設定画面がシャッフル用のタスクを保持し、有効な間は選択した間隔で背景画像を切り替える。
- 切り替え対象はユーザー背景画像のみとし、同梱サンプルは対象外にする。
- 直前の画像とは異なる画像を選ぶ。
- 切り替え時は背景画像の状態・設定プルダウン・保存内容を更新する。
- ランダムの有無や間隔が変わったときは、タスクを破棄して新しい間隔で開始し直す。

## 影響

- 1分〜1日の間隔で背景画像が自動的に切り替わる。
- アプリ起動中だけ動作し、終了すると停止する。
- JXLなどの大きい画像では、切り替え時にデコードの待ち時間が発生する場合がある。
- ユーザー背景画像が2枚未満の場合は切り替わらない。
