# 同一URLのキュー重複登録を禁止する

- ステータス: Accepted
- 決定日: 2026-11-27
- 影響範囲: 一括ダウンロード、かんたんダウンロード、キュー

## 背景

同じURLを複数回登録すると、同じ動画のダウンロードが重複したり、キュー内で対象を区別しにくくなったりする。一括入力と単一URL入力の両方で、重複登録を防ぐ必要がある。

## 決定

- 前後の空白を除いたURL文字列が完全一致する場合、キュー内の項目と重複したものは追加しない。
- 一括入力の中で同じURLが複数回現れても、1件だけ追加する。
- 完了・失敗・スキップ済みを含め、キューに残っている間は重複追加を禁止する。
- 項目をキューから削除した後は、そのURLを再び追加できるようにする。
- 重複で追加されなかったURLは、追加件数には含めない。

## 理由

キュー内の完全一致を確認するだけで、動画のダウンロード重複と利用者の混乱を防げる。URLの別表記を無理に正規化すると、パスやクエリの意味を変えてしまうため、完全一致を採用する。

## 結果

- 一括ダウンロードとかんたんダウンロードで、同じURLを重複登録できない。
- 重複URLだけを追加しようとした場合は、追加されずに確認を促す。
- キューから削除するまで、完了済みのURLも再登録できない。
