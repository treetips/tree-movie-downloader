# 音声用コンテナの選択

- ステータス: Accepted
- 日付: 2026-11-23

## 背景

- URL追加ダイアログではコンテナを選べず、設定画面の共通設定だけが使われていた。
- 画質で `映像なし` を選んでもコンテナは mp4・mkv・WebM のままで、音声だけの出力に映像用コンテナを指定するのは実態に合わない。
- yt-dlpの `--merge-output-format` と `--remux-video` は音声のみの変換には適さず、mp3などへの変換もできない。

## 決定

- URL追加ダイアログにコンテナのプルダウンを追加し、追加するすべてのURLへ適用する。
- 画質が `映像なし` 以外のときは映像用コンテナ（mp4・mkv・WebM）、`映像なし` のときは音声用コンテナ（m4a・mp3・opus・flac）を表示する。
- `映像なし` の初期値は m4a とする。画質を切り替えたとき、同じ種類のコンテナを選んでいれば引き継ぎ、種類が変わった場合はその種類の初期値へ置き換える。
- 画質の変更に合わせて、キュー行とサイト見出しのコンテナメニューも同じ選択肢へ切り替える。
- `映像なし` のダウンロードはyt-dlpの `-x --audio-format` で音声ファイルとして出力する。映像ありは従来どおり `--merge-output-format` と `--remux-video` を使う。
- 音声用コンテナが非可逆形式（m4a・mp3・opus）のときは、選択した音質（最高・192 kbps・128 kbps）を `--audio-quality` へ引き継ぐ。flacは可逆のため指定しない。
- 設定画面のコンテナ共通設定は映像用のみとし、新しいURLの映像用コンテナの初期値にする。

## 影響

- `映像なし` の出力拡張子は、選択した音声用コンテナになる（初期値は m4a）。
- 音声用コンテナへの変換はffmpegで行うため、mp3などでは再エンコードが発生する。
- キュー項目の画質を変えると、コンテナが自動で同じ種類の値へ変わる。
